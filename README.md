# All-Crochet
A modern crochet marketplace app where users can browse, buy, and showcase handmade crochet products.

## Features
- Browse crochet products
- Product categories and tags
- Product detail pages
- User authentication
- Seller profiles
- Image uploads
- Responsive and clean UI

## Tech Stack
- React Native / Expo
- Firebase Authentication
- Firestore Database
- Firebase Storage
